Experiment context

Method

You log in to the site yourself on the browser screen that opens when the experiment starts; the session is not saved to disk. Read-only protection is best effort only: non-GET requests and WebSockets are blocked and navigation stays on the target host, but endpoints that change data on GET can't be blocked, and pages that read data with POST may break. Page text and screenshots go to the model provider through CLIProxyAPI. Use a separate test account on live environments.

Writes are on: agents can change real data. Personas use the same session in turn; one persona's changes carry over to the next.
